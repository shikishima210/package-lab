# パッケージ展開図ラボ

厚紙パッケージの展開図（ダイライン）を寸法から生成し、組み立てを3Dで確かめられるブラウザツールです。`index.html` を開くだけで動きます（ビルド不要）。

**デモ**：https://shikishima210.github.io/package-lab/

## できること

- **箱の型**：郵送箱、キャラメル箱、トレー、スライド箱（トレー＋スリーブ）、かぶせ箱
- **特殊な形**：三角柱・六角柱など（面の数3〜48）、円筒、花びら箱
- **袋**：開封帯付き平袋、ミニチップス袋（背貼り・ギザギザ端）
- **中に入れる部品**：カップ穴付き台座、仕切り板
- **面に置く部品**：窓、持ち手穴、吊り下げ穴、ミシン目（回転可）、文字、画像（ファイル選択・貼り付け・ドラッグ＆ドロップ）
- **色はCMYK（%）で指定**（画面表示は簡易換算の目安）
- 数値入力とスライダーを並べたパラメータ欄
- スマホ対応（アイビスペイント風の画面：下のツールバー・スライダー・下から出るウィンドウ）
- 3Dで面をクリックして部品を配置、ドラッグで移動、元に戻す／やり直す
- 内側に重なる板への穴の自動追加、折り線にかかる部品などの警告
- 実寸（mm）のSVG書き出し（切り線・折り線・ミシン目・印刷のレイヤー分け。画像は印刷レイヤーに埋め込み）

## 使い方

1. 左上の「＋ 追加」から箱や袋を選ぶ
2. 右のプロパティで寸法・紙・構造を調整
3. 上のツールで面をクリックして窓や文字を配置
4. 下のスライダーで「展開 → 分解図 → 完成」を確認
5. 「すべてSVG保存」または「コピー」で書き出し

## 技術

HTML / CSS / JavaScript、3D表示は [Three.js](https://threejs.org/) r128（CDN読み込み）。
